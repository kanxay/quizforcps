# ແຜນຈັດຕັ້ງປະຕິບັດ: ປິດການສະແດງຜົນສອບເສັງ ແລະ ປ່ຽນເປັນໜ້າຢືນຢັນການສົ່ງບົດສອບ (Clean Submission Confirmation)

ແຜນການນີ້ກຳນົດການປັບປຸງລະບົບສອບເສັງອາສາສະໝັກອອນລາຍ ໂຮງໝໍແຂວງຈຳປາສັກ ໂດຍການ**ຕັດການສະແດງຄະແນນ, ເປີເຊັນ, ສະຖານະຜ່ານ/ບໍ່ຜ່ານ, ໃບຢັ້ງຢືນ (Certificate), ແລະ ການສະເລີຍຄຳຕອບ (Answer Review)** ອອກຈາກໜ້າຈໍຂອງຜູ້ສອບເສັງ (ອາສາສະໝັກ) ທັງໝົດຕາມຄຳຮ້ອງຂໍ, ໂດຍປ່ຽນມາສະແດງເປັນໜ້າຢືນຢັນການສົ່ງບົດສອບເສັງທີ່ເປັນທາງການ, ສະອາດ ແລະ ສຸພາບ. ໃນຂະນະດຽວກັນ ຄູອາຈານ ແລະ ຜູ້ດູແລລະບົບ (Admin) ຍັງຄົງສາມາດເບິ່ງຄະແນນ, ກວດຂໍ້ສອບອັດຕະໄນ ແລະ ອອກໃບຢັ້ງຢືນໄດ້ຄືເກົ່າ.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **ຂໍ້ຕົກລົງທີ່ໄດ້ຮັບການຢືນຢັນຈາກຜູ້ໃຊ້ (Confirmed Decisions):**
> 1. **ໜ້າຈໍຫຼັງກົດສົ່ງບົດສອບຂອງນັກຮຽນ**: ສະແດງໜ້າຢືນຢັນການສົ່ງບົດສອບເສັງ (Clean confirmation screen) ທີ່ບໍ່ມີຄະແນນ, ບໍ່ມີເປີເຊັນ, ບໍ່ມີສະຖານະຜ່ານ/ຕົກ, ບໍ່ມີໃບຢັ້ງຢືນ, ແລະ ບໍ່ມີການສະເລີຍຄຳຕອບ.
> 2. **ສິດຂອງອາຈານ ແລະ Admin**: ອາຈານ ແລະ Admin ຍັງຄົງສາມາດເບິ່ງຄະແນນທັງໝົດ, ກວດຂໍ້ສອບ, ແລະ ພິມໃບຢັ້ງຢືນ (Certificate) ໃນ Dashboard ໄດ້ຕາມປົກກະຕິ.

### 1. ການປ່ຽນແປງໜ້າຈໍຜູ້ສອບເສັງ (Examinee Experience)

- **ສິ່ງທີ່ຈະຕັດອອກຈາກໜ້າຈໍຜູ້ສອບເສັງ (Removed completely from student view)**:
  - ຂໍ້ຄວາມສະແດງຜົນຜ່ານ/ຕົກ: *"ຍິນດີດ້ວຍ! ທ່ານສອບເສັງຜ່ານແລ້ວ"* ຫຼື *"ທ່ານຍັງບໍ່ຜ່ານເກນການສອບເສັງ"*
  - ແຖບສະແດງຄະແນນ: ຄະແນນປາລະໄນ, ຄະແນນອັດຕະໄນ, ຄະແນນລວມ, ແລະ ເປີເຊັນ (%)
  - ປຸ່ມພິມໃບຢັ້ງຢືນ: *"ເບິ່ງ ແລະ ພິມໃບຢັ້ງຢືນ (Certificate)"*
  - ສ່ວນສະເລີຍຄຳຕອບລະອຽດ: *"ກວດກາຄຳຕອບລະອຽດ (Answer Review)"* ພ້ອມລາຍການຂໍ້ສອບ, ຄຳຕອບທີ່ເລືອກ ແລະ ຄະແນນແຕ່ລະຂໍ້

- **ສິ່ງທີ່ຈະສະແດງແທນ (New Submission Confirmation Screen)**:
  - **ໄອຄອນ & ຫົວຂໍ້**: ໄອຄອນໃບຢັ້ງຢືນການສົ່ງສຳເລັດສີຂຽວ (`CheckCircle2` / `Send`) ພ້ອມຫົວຂໍ້ໃຫຍ່ **"ສົ່ງບົດສອບເສັງສຳເລັດແລ້ວ" (Exam Submitted Successfully)**.
  - **ຂໍ້ຄວາມຊີ້ແຈງ**: *"ຂໍ້ມູນ ແລະ ຄຳຕອບຂອງທ່ານໄດ້ຖືກບັນທຶກເຂົ້າສູ່ລະບົບຮຽບຮ້ອຍແລ້ວ. ຄະນະກຳມະການ ແລະ ຄູອາຈານຈະດຳເນີນການກວດກາ ແລະ ປະກາດຜົນສອບເສັງຕາມພາຍຫຼັງ."*
  - **ບັດຢືນຢັນຂໍ້ມູນການສົ່ງ (Submission Receipt Card)**:
    - ຫົວຂໍ້ບົດສອບເສັງ (Exam Title)
    - ລະຫັດຜູ້ສອບເສັງ (Candidate Code)
    - ຊື່ ແລະ ນາມສະກຸນ (Full Name)
    - ສັງກັດ / ແຂວງ (Department / Province)
    - ວັນທີ ແລະ ເວລາທີ່ສົ່ງ (Submission Timestamp)
    - ສະຖານະ: ບັນທຶກສຳເລັດແລ້ວ (Submitted)
  - **ປຸ່ມດຳເນີນການ**: 
    - ປຸ່ມ **"ກັບຄືນໜ້າຫຼັກ / ລາຍການບົດສອບ"** ເພື່ອໃຫ້ນັກຮຽນອອກຈາກຫ້ອງສອບເສັງໄດ້ຢ່າງປອດໄພ.

### 2. ຄວາມປອດໄພ ແລະ ຖານຂໍ້ມູນ (Data Integrity & Permissions)

- **ການບັນທຶກຂໍ້ມູນລົງ Turso**:
  - ຄຳຕອບ ແລະ ຄະແນນ (Objective score ທີ່ລະບົບຄິດໄລ່ອັດຕະໂນມັດ) ຍັງຄົງຖືກບັນທຶກລົງຕາຕະລາງ `submissions` ໃນ Turso ຕາມປົກກະຕິ.
  - ບໍ່ມີການສູນເສຍຂໍ້ມູນຄະແນນໃນຖານຂໍ້ມູນ.
- **Admin Dashboard & Teacher Dashboard**:
  - ອາຈານ ແລະ Admin ຍັງສາມາດເປີດເບິ່ງລາຍການຜົນສອບເສັງ, ກວດຄະແນນອັດຕະໄນ, ເບິ່ງຄະແນນລວມ, ແລະ ກົດພິມໃບຢັ້ງຢືນໃຫ້ແກ່ຜູ້ທີ່ສອບເສັງຜ່ານໄດ້ຢ່າງຄົບຖ້ວນ.

### 4. ຂັ້ນຕອນການທົດສອບ (Verification Plan)

1. **ທົດສອບການສອບເສັງຂອງນັກຮຽນ (Student Exam Flow)**:
   - ເຂົ້າສູ່ລະບົບເປັນນັກຮຽນ/ອາສາສະໝັກ -> ເລືອກບົດສອບເສັງ -> ຕອບຂໍ້ສອບ -> ກົດສົ່ງບົດສອບເສັງ.
   - ກວດສອບວ່າໜ້າຈໍສະແດງສະເພາະ *"ສົ່ງບົດສອບເສັງສຳເລັດແລ້ວ"* ພ້ອມບັດຢືນຢັນການສົ່ງ, ບໍ່ມີຄະແນນ, ບໍ່ມີເປີເຊັນ, ບໍ່ມີໃບຢັ້ງຢືນ, ແລະ ບໍ່ມີສະເລີຍຄຳຕອບເລີຍ.
2. **ທົດສອບ Dashboard ຂອງອາຈານ ແລະ Admin (Teacher & Admin Flow)**:
   - ເຂົ້າສູ່ລະບົບເປັນ Teacher ຫຼື Admin -> ກວດສອບຕາຕະລາງຜົນສອບເສັງ.
   - ກວດສອບວ່າຄະແນນຍັງຄົງບັນທຶກຖືກຕ້ອງ, ສາມາດກວດໃຫ້ຄະແນນອັດຕະໄນ ແລະ ພິມໃບຢັ້ງຢືນໄດ້ຄືເກົ່າ.
3. **ກວດສອບລະບົບ Build & Lint**:
   - ທົດສອບ `compile_applet` ແລະ `lint_applet` ໃຫ້ຜ່ານ 100% ໂດຍບໍ່ມີ error.
